

\# Tobago Moon \& Tide Widget



An embeddable lunar phase and tide classification calendar

for Tobago, Trinidad and Tobago.



\## Features



\- Current moon phase

\- Moon illumination

\- Lunar age

\- Monthly astronomical phase calendar

\- New Moon

\- First Quarter

\- Full Moon

\- Last Quarter

\- Spring and Neap tide classifications

\- Tobago local time (AST, UTC-4)

\- Responsive website embedding

\- Automatic iframe height adjustment



\## Technology



\### Frontend

\- HTML

\- CSS

\- JavaScript



\### Backend

\- Python

\- FastAPI

\- PyEphem



\## Hosting



\- Netlify: Widget hosting

\## API Endpoints



\- /api/moon

\- /api/phases

\- /api/tides



\## Location



Tobago, Trinidad and Tobago



Timezone: America/Port\_of\_Spain



\## Disclaimer



Spring and neap classifications are estimates based

on lunar phase windows.



They are not actual tide heights or exact high and

low tide predictions.
